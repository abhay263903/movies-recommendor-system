# 🎬 Movie Recommendation System

A Movie Recommendation System built with Python and Streamlit that helps users discover movies similar to their selected movie.

## 📌 Project Overview

This project explores how machine learning techniques can be used to recommend movies based on similarity between movie data.

The application provides an interactive interface where users can select a movie and view similar recommendations.

## ✨ Features

- 🎥 Movie selection and recommendations
- 🤖 Similarity-based recommendation logic
- 🖥️ Interactive web interface using Streamlit
- 🐍 Python-based implementation

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/abhay263903/movies-recommendor-system.git
```

### 2. Open the project folder

```bash
cd movies-recommendor-system
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```
